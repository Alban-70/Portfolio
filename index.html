03 / PROJETS EN COURS

Un projet vivant.

Un projet en cours de développement

PROJET EN COURS

Suivi et analyse des plantes

Un système connecté pour suivre les plantes, centraliser les données de capteurs et les consulter depuis une interface web. Une application mobile permet aussi de les photographier afin de transmettre les images à une IA pour analyse.

  • Node.js · REST
  • Vue.js
  • Java · Threads
  • MongoDB
  • Flutter
  • Python · IA
  • Microcontrôleurs
  • Serveur multimédia
  • Docker
FLUX DE DONNÉES
  1. 01
    Acquisition

    Relevés des capteurs sur microcontrôleurs et photos prises depuis l’application mobile Flutter.

  2. 02
    Traitement & IA

    Centralisation via l’API REST Node.js et le serveur Java multithread, puis analyse d’image par IA en Python.

  3. 03
    Restitution

    Stockage des données dans MongoDB et consultation en temps réel sur l’interface web Vue.js.

DÉFIS TECHNIQUES
  • Communication multi-services : faire dialoguer des microcontrôleurs, un serveur Java multithread et une API Node.js.
  • Traitement asynchrone : gérer l’envoi des photos depuis Flutter vers le modèle d’IA Python sans bloquer l’interface.
  • Déploiement reproductible : isoler et orchestrer l’ensemble des briques techniques avec Docker.
